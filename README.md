#  интернет-магазин Skystore
Skystore - это отличный вариант хранения ваших плагинов и примеров кода,
который вы бы хотели продать
## Содержание приложения
В приложении содержится:
1. Каталог - предлагающий услуги
2. Контакты с обратной связью
### Требования
Python 3.10+
